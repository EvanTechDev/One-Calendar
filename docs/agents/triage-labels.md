# Triage Labels

These labels are scoped to the Core team in Linear.

| Canonical role | Linear label | Meaning |
| --- | --- | --- |
| `needs-triage` | `needs-triage` | Maintainer needs to evaluate the issue. |
| `needs-info` | `needs-info` | More information is required. |
| `ready-for-agent` | `ready-for-agent` | Fully specified and ready for an agent once blockers are done. |
| `ready-for-human` | `ready-for-human` | Requires human implementation. |
| `wontfix` | `wontfix` | Will not be actioned. |

Use the corresponding label whenever an engineering skill names a triage role.
Labels describe triage readiness; Linear issue status and blocking relationships
separately describe progress and execution order.
