This major release turns Zentra Calendar into an AI-ready, faster, and more secure scheduling tool. It ships an MCP server so AI assistants can read and manage your calendar, a Redis cache layer for snappier loads, field-level encryption for your data, and a fully migrated data layer that keeps every view in sync in real time.

## Features

- feat: add MCP server with all calendar tools plus rate limiting and audit logging
- feat: implement OAuth Device Code Grant and Authorization Code Grant with PKCE for AI clients
- feat: add OAuth dynamic client registration to the MCP server
- feat: show redirect URI and scopes on the OAuth authorize page, validate HTTPS redirect
- feat: add MCP settings UI components and management API routes
- feat: add Redis cache layer for sessions and events with automatic invalidation
- feat: add field-level encryption and CRUD APIs
- feat: add DataProvider + API client frontend layer, migrating all data from localStorage
- feat: add Astro web marketing site with theme-aware logo favicon
- feat: redirect unauthenticated /app users to /sign-up
- feat: make month-view remaining events clickable with year-view popover scroll
- feat: add new data refresh callbacks and update import paths in locales
