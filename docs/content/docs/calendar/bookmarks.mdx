Bookmark events you want to revisit without remembering their dates. A bookmark points to the existing event; it does not make a copy, change its schedule, or add a reminder.

## Keep a shortlist across dates

Use bookmarks for events you repeatedly consult, such as an upcoming review, a travel reservation, or a meeting with preparation notes. Open Bookmarks from Calendar's sidebar tools and select an entry to navigate to its event.

Bookmarks can open events outside the date range currently visible in the calendar. You do not need to navigate month by month first. For a recurring event, check the occurrence date shown in the preview before editing it.

## Search within your bookmarks

The bookmark panel filters the titles and descriptions of bookmarked events. It searches your shortlist, not every event in Calendar.

If you remember an event but never bookmarked it, use [event search](/docs/calendar/search). If a bookmark search returns nothing, clear its text filter before assuming the entry was removed.

## Choose what the ordering means

The initial ordering shows the most recently added bookmarks first. Change the sort when you need to find the next appointment or a particular title.

| Sort                                | Meaning                            | Use it for                             |
| ----------------------------------- | ---------------------------------- | -------------------------------------- |
| Title, ascending or descending      | Alphabetical order of event titles | Finding a named project or meeting     |
| Event date, ascending or descending | The event's start date             | Reviewing earlier or later commitments |
| Bookmarked, newest or oldest        | When the bookmark was created      | Returning to recently saved references |

The bookmark date is not the event's last-edit date. Editing an event does not make it a newly created bookmark. The selected sort is remembered in this browser.

## Remove a bookmark without canceling the event

Remove an entry from Bookmarks when it no longer belongs in your shortlist. This removes the bookmark, not the event or its invitations.

To cancel an event, open it and use the event's deletion action with the appropriate [recurrence scope](/docs/calendar/recurring-events). A bookmark is not an independent archive of an event that has been deleted or is no longer accessible.

## Choose between bookmarks and countdowns

A bookmark helps you return to event details. A [countdown](/docs/calendar/countdowns) helps you track the distance to a date. Use an [event reminder](/docs/calendar/reminders) when you need a notification before something starts.
