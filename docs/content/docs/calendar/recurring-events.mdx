A recurring event generates occurrences from one rule. Repeat daily, weekly, monthly, or yearly, with an interval and an optional end date or occurrence count.

## Choose a change scope

Before editing or deleting, decide which dates should change.

| Scope                     | Use it for                                       | Result                                                                                              |
| ------------------------- | ------------------------------------------------ | --------------------------------------------------------------------------------------------------- |
| This event                | Postponing this week's meeting                   | Only the selected occurrence changes; other dates keep the original rule.                           |
| This and following events | Moving the regular meeting from next week onward | Earlier dates stay intact; the selected occurrence and future dates use the new settings.           |
| All events                | Correcting settings for the whole series         | The entire series changes. This option is available when editing from the series' first occurrence. |

If you open an occurrence in the middle of a series, the whole-series option is not available. Return to the first occurrence rather than repeatedly applying a change to following events.

## Reschedule one occurrence

To postpone one meeting, keep the series rule and create an exception for that date.

<Steps>
<Step>
### Open the intended occurrence

Check the date in the preview. Identical titles can refer to different occurrences of the same series.

</Step>
<Step>
### Apply the change to this event

Change the start and end times, then confirm the single-event scope when saving. Next week's meeting keeps its original schedule.

</Step>
<Step>
### Check the next occurrence

Review the rescheduled date and the next meeting to confirm that a temporary change did not become a permanent one.

</Step>
</Steps>

## Change the schedule from a date onward

Editing this and following events splits the schedule at the selected occurrence. Earlier dates remain in the original segment; later dates use the new settings. When you edit again, treat each segment as its own series with its own first occurrence.

The same scopes apply to deletion. Deleting one occurrence excludes that date from the rule. Deleting this and following events ends the remaining schedule.

## Confirm invitation scope separately

An event change does not determine which dates a newly added participant is invited to. You can reschedule only this week's meeting while inviting a colleague to future meetings. Check the invitation confirmation before sending. See [Invitations](/docs/calendar/invitations).
