This major release turns One Calendar into an AI-ready, faster, and more secure scheduling tool. It ships an MCP server so AI assistants can read and manage your calendar, a Redis cache layer for snappier loads, field-level encryption for your data, and a fully migrated data layer that keeps every view in sync in real time.
